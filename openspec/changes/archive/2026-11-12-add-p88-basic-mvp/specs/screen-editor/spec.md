# Spec Delta

## Purpose

電源投入から `Ok` プロンプトまでの起動と、キーボードで画面上の任意の行を編集・入力する N88-BASIC 風スクリーンエディタの振る舞いを定める。

## ADDED Requirements

### Requirement: 起動画面
システムは起動するとテキスト画面を消去し、1 行目にタイトルと空きメモリのバイト数を、続けて `Ok` を表示して入力待ちにならなければならない (SHALL)。

#### Scenario: 電源投入
- **WHEN** マシンが起動する
- **THEN** タイトル行と `<数値> Bytes free` と `Ok` が表示され、その下でカーソルが点滅する

### Requirement: 文字入力
システムはキーボードで入力された ASCII 印字可能文字をカーソル位置に書き込み、カーソルを右へ進めなければならない (SHALL)。行末に達したら次の行の先頭へ進み、最下行からはみ出す場合は画面を 1 行上へスクロールする。

#### Scenario: 文字の入力
- **WHEN** 空の行で `ABC` と打鍵する
- **THEN** 画面に `ABC` が表示され、カーソルは `C` の右にある

### Requirement: カーソル移動と編集キー
システムは矢印キーによる上下左右の移動、`BS` (左の文字を削除して詰める)、`DEL` (カーソル位置の文字を削除して詰める)、`INS` (挿入モードの切替)、`HOME` (カーソルを左上へ)、`Shift+HOME` または `CLR` 相当 (画面消去) を提供しなければならない (SHALL)。

#### Scenario: BS で削除
- **WHEN** `ABC` と打鍵して `BS` を押す
- **THEN** 画面に `AB` が残り、カーソルは `B` の右にある

#### Scenario: 挿入モード
- **WHEN** `AC` と打鍵し、左矢印を 1 回押し、`INS` を押してから `B` を打鍵する
- **THEN** 画面に `ABC` が表示される

### Requirement: RET で画面上の行を入力
システムは RET が押されると、カーソルのある論理行 (折り返しで続く物理行を含む) の画面上の内容を入力行として処理しなければならない (SHALL)。カーソルが行のどこにあっても論理行全体を対象とする。

#### Scenario: LIST した行を書き換えて再入力
- **WHEN** `10 PRINT 1` を `LIST` 表示し、その行にカーソルを移して `1` を `2` に書き換えて RET を押し、再度 `LIST` する
- **THEN** `10 PRINT 2` が表示される

### Requirement: 全角文字上のカーソル
システムは全角文字が占める 2 セルの右側セルにカーソルを置いてはならず、全角文字の削除は 2 セル分を詰めなければならない (SHALL)。

#### Scenario: 全角文字をまたぐ移動
- **WHEN** `PRINT "あ"` の出力行で、`あ` の左セルから右矢印を 1 回押す
- **THEN** カーソルは `あ` の次の文字位置へ移動する

### Requirement: 実行の中断
システムはプログラム実行中に `STOP` キー (ESC) または `Ctrl+C` が押されたら実行を中断し、`Break in <行番号>` を表示して `Ok` に戻らなければならない (SHALL)。`CONT` でその位置から再開できる。

#### Scenario: 無限ループの中断
- **WHEN** `10 GOTO 10` を `RUN` してから ESC を押す
- **THEN** `Break in 10` と `Ok` が表示される

### Requirement: INKEY$ によるキー取得
システムは `INKEY$` で、押されたキーの文字を待たずに 1 文字返し、何も押されていなければ空文字列を返さなければならない (SHALL)。カーソル移動キーは N88-BASIC と同じ制御文字コード (右 `&H1C`、左 `&H1D`、上 `&H1E`、下 `&H1F`) で返す。

#### Scenario: キーなし
- **WHEN** キーを押さずに `PRINT LEN(INKEY$)` を実行する
- **THEN** ` 0` が表示される

### Requirement: 英字キーボード入力のみ
システムは本変更ではキーボードから ASCII 印字可能文字のみを入力として受け付けなければならず (SHALL)、それ以外の文字は `CHR$` やファイルの読み込みで扱う。

#### Scenario: 日本語は CHR$ で表示
- **WHEN** `PRINT CHR$(&H65E5)` を実行する
- **THEN** `日` が表示される
