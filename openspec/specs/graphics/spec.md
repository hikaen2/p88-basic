# graphics Specification

## Purpose

640x400 ドット 16 色のグラフィック画面をテキスト画面と重ねて表示し、16 色パレットと `PSET`・`LINE`・`CIRCLE`・`PAINT` で描画する振る舞いを定める。

## Requirements

### Requirement: グラフィック画面とテキストの重ね合わせ
システムは 640x400 ドット・16 色のグラフィック画面を、テキスト画面と同じ 640x400 の画面に 1 対 1 で表示し、その上にテキスト画面を重ねなければならない (SHALL)。テキストの文字ドットはグラフィックより前面に、文字の背景はグラフィックが透けて見えるようにする。

#### Scenario: 線の上に文字
- **WHEN** `LINE (0,0)-(639,399),4,BF:PRINT "HELLO"` を実行する
- **THEN** 画面全体が緑になり、その上に `HELLO` が読める状態で表示される

### Requirement: 16 色パレット
システムはテキストとグラフィックで共通の 16 エントリのパレットを持ち、各色番号を 4096 色 (RGB 各 4 ビット) のいずれかで表示しなければならない (SHALL)。起動時の既定値は次のとおりとする (`&HRGB`): 0 `&H000` 黒、1 `&H00F` 青、2 `&HF00` 赤、3 `&HF0F` 紫、4 `&H0F0` 緑、5 `&H0FF` 水色、6 `&HFF0` 黄、7 `&HFFF` 白、8 `&H777` 灰、9〜15 は 1〜7 の暗い色 (各成分 `7`)。

#### Scenario: 既定の色
- **WHEN** 起動直後に `PSET (0,0),2` を実行する
- **THEN** (0,0) が純粋な赤 (RGB 各 4 ビットで F,0,0) で表示される

### Requirement: パレットの変更
システムは `COLOR=(p,c)` でパレット番号 p (0〜15) の表示色を c (`&H000`〜`&HFFF`、`&HRGB` 形式) に変更し、画面上のその番号の文字とドットの色を直ちに変えなければならない (SHALL)。`COLOR=NEW` は既定のパレットに戻す。範囲外の値は `Illegal function call` とする。

#### Scenario: 描画済みの色を変える
- **WHEN** `LINE (0,0)-(99,99),9,BF:COLOR=(9,&HF80)` を実行する
- **THEN** 描画済みの矩形がオレンジ色に変わる

#### Scenario: 既定に戻す
- **WHEN** `COLOR=(7,&H000):COLOR=NEW` を実行する
- **THEN** 色番号 7 の文字が白に戻る

### Requirement: 座標と色の範囲
システムは x 0〜639、y 0〜399 の座標と色 0〜15 (パレット番号) を受け付けなければならない (SHALL)。画面外の座標は描画を切り捨ててエラーにせず、色が範囲外なら `Illegal function call` とする。色の省略時は 7 とする。

#### Scenario: 画面外への線
- **WHEN** `LINE (-100,-100)-(700,300),7` を実行する
- **THEN** エラーにならず、画面内の部分だけが描かれる

### Requirement: PSET と PRESET
システムは `PSET (x,y),c` で 1 ドットを色 c で描き、`PRESET (x,y)` で 1 ドットを 0 (黒) にしなければならない (SHALL)。最後に描いた点を「最終参照点」として記憶する。

#### Scenario: 点を打つ
- **WHEN** `PSET (100,50),2` を実行する
- **THEN** 座標 (100,50) が赤になる

### Requirement: LINE
システムは `LINE (x1,y1)-(x2,y2),c` で線分を、`,B` で枠を、`,BF` で塗りつぶした矩形を描かなければならない (SHALL)。始点を省略した `LINE -(x2,y2)` は最終参照点から描く。

#### Scenario: 塗りつぶし矩形
- **WHEN** `LINE (10,10)-(20,20),6,BF` を実行する
- **THEN** (10,10) から (20,20) までの矩形 (両端含む) が黄色で塗られる

### Requirement: CIRCLE
システムは `CIRCLE (x,y),r,c` で中心 (x,y)・半径 r の円を描かなければならない (SHALL)。ドットは正方形なので縦横比の補正はしない。

#### Scenario: 円を描く
- **WHEN** `CIRCLE (320,200),80,5` を実行する
- **THEN** 画面中央に水色の円が真円に見える形で描かれる

### Requirement: PAINT
システムは `PAINT (x,y),c,b` で (x,y) を含み境界色 b で囲まれた領域を色 c で塗りつぶさなければならない (SHALL)。b を省略した場合は c を境界色とする。

#### Scenario: 円の内側を塗る
- **WHEN** `CIRCLE (320,200),50,2:PAINT (320,200),2` を実行する
- **THEN** 円の内側が赤で塗りつぶされ、円の外側は変化しない

### Requirement: POINT
システムは `POINT(x,y)` で指定ドットの色番号を返し、画面外なら -1 を返さなければならない (SHALL)。

#### Scenario: 色の読み取り
- **WHEN** `PSET (5,5),3:PRINT POINT(5,5)` を実行する
- **THEN** ` 3` が表示される
