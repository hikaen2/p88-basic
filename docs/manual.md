# p88 BASIC マニュアル

p88 BASIC は N88-BASIC 風の BASIC です。行番号付きのプログラムを画面エディタで入力し、`RUN` で実行します。
N88-BASIC と同じ書き方でだいたい動きますが、完全な互換はありません (末尾の「N88-BASIC との違い」を参照)。

## 1. 画面とキー操作

起動すると次の画面になり、入力を待ちます。

```
p88 BASIC Version 0.1
1048576 Bytes free
Ok
```

画面は 80 桁 × 25 行 (`WIDTH 80,20` で 20 行) のテキストと、640×400 ドット 16 色のグラフィックの重ね合わせです。
文字は Unicode BMP (漢字・かなを含む) を表示でき、全角文字は 2 桁を使います。キーボードから入力できるのは ASCII 文字だけです。

### 画面エディタ

画面上のどこでも、カーソルを移動して書き換え、RET (Enter) を押すとその行が入力されます。
`LIST` で表示した行を直して RET を押せば、その行が置き換わります。

| キー | 動作 |
|---|---|
| 文字キー | カーソル位置に書く (挿入モードでは挿入) |
| RET | カーソルのある行を入力する (折り返して続く行もまとめて 1 行) |
| ← → ↑ ↓ | カーソル移動 |
| BS | カーソルの左の 1 文字を消して詰める |
| DEL | カーソル位置の 1 文字を消して詰める |
| INS | 挿入モードの切り替え (カーソル移動・RET で解除) |
| HOME | カーソルを左上へ |
| PageUp / PageDown | `EDIT` で表示したプログラムのページ送り |
| End (HELP) | `EDIT .` と同じく EDIT モードに入る |
| Shift+HOME / Ctrl+HOME | 画面を消す |
| ESC / Ctrl+C | 実行中のプログラムを止める (`Break in 行番号`) |

キー配列は JIS が既定です。US 配列は SD カードの `cmdline.txt` に `keymap=US` と書きます。

## 2. プログラムの入力

- 数字で始まる行は、プログラムの行として登録されます (行番号 0〜65529)。
- 同じ行番号を入力すると置き換わり、行番号だけを入力するとその行が消えます。
- 数字で始まらない行は、すぐに実行されます (ダイレクトモード)。
- 1 行に `:` で区切って複数の文を書けます。
- キーワードと変数名は大文字でも小文字でもよく、`LIST` では大文字で表示されます。文字列とコメントの中身はそのままです。
- 行番号のあとの 2 つ目以降の空白はインデントとして残ります。
- `?` は `PRINT` の省略形です。

```
10 for i=1 to 3
20   ? i;
30 next
list
10 FOR I=1 TO 3
20   PRINT I;
30 NEXT
Ok
run
 1  2  3
Ok
```

## 3. データ

### 型と変数

| 型 | 接尾辞 | 内容 |
|---|---|---|
| 整数 | `%` | -32768〜32767 |
| 単精度 | `!` `#` または なし | IEEE 754 単精度 (有効 7 桁ほど)。`#` も単精度として扱う |
| 文字列 | `$` | Unicode BMP の文字列 |

- 変数名は英字で始まり、英数字と `.` が続きます。名前はすべての文字で区別されます。
- 型が違えば同じ名前でも別の変数です (`A`、`A%`、`A$`)。
- 代入していない変数は 0 か空文字列です。
- 変数名をキーワードで始めることはできません。たとえば `TOTAL` は `TO TAL` と解釈されます。

### 定数

| 書き方 | 例 |
|---|---|
| 整数 | `123` `-5` |
| 小数・指数 | `1.5` `.5` `1E3` `2.5E-4` |
| 16 進 | `&HFF` `&H6F22` |
| 文字列 | `"ABC"` `"漢字"` |

整数の計算結果が整数の範囲を超えると、自動的に単精度になります。

### 配列

```
DIM A(10), B$(5,3)
```

- 添字は 0 から指定した値までです。
- `DIM` せずに使った配列は、各次元の添字が 0〜10 になります。
- 同じ配列を 2 回 `DIM` すると `Duplicate Definition` になります。

## 4. 式と演算子

優先順位の高い順:

| 順位 | 演算子 |
|---|---|
| 1 | `^` (べき乗。右から計算するので `2^3^2` は `2^9` = 512) |
| 2 | `-` (符号) |
| 3 | `*` `/` |
| 4 | `\` (整数の割り算。JIS キーボードでは `¥`) |
| 5 | `MOD` |
| 6 | `+` `-` |
| 7 | `=` `<>` `<` `>` `<=` `>=` |
| 8 | `NOT` |
| 9 | `AND` |
| 10 | `OR` |
| 11 | `XOR` |

- 比較の結果は、真が -1、偽が 0 です。`IF` は 0 以外を真とみなします。
- `AND` `OR` `XOR` `NOT` は整数のビット演算です。
- 文字列は `+` で連結し、比較演算子で文字コード順に比べられます。

## 5. 文

`[ ]` は省略できる部分です。

### プログラムの操作

| 文 | 説明 |
|---|---|
| `LIST [開始][-[終了]]` | プログラムを表示する。例: `LIST 100`、`LIST 100-200`、`LIST -50`、`LIST 300-` |
| `EDIT 行番号` / `EDIT .` | 画面を消し、その行から 1 画面分を表示する (下の「EDIT モード」を参照)。`.` は最後に入力した行か、エラー・中断が起きた行 |
| `RUN [行番号]` | 変数を消して、先頭 (または指定の行) から実行する |
| `NEW` | プログラムと変数を消す |
| `CONT` | `STOP` や ESC で止めたプログラムを続ける |

### EDIT モード

`EDIT` を実行するか End (HELP) キーを押すと EDIT モードになり、PageDown で次の画面、PageUp で前の画面のプログラムを表示します。
画面上の行を直して RET を押せば、その行が置き換わります。
`RUN` や `GOTO` など、行番号のない文を入力して実行すると EDIT モードは終わります。

### 出力と入力

**`PRINT [式][; 式][, 式]...`** は画面に出力します。
- `;` は続けて出力し、`,` は次の 14 桁ごとの位置まで進めます。
- 最後が `;` か `,` なら改行しません。
- 数値は、正なら前に空白、後ろにも空白を 1 つ付けて出力します (`PRINT 1;-2` → ` 1 -2 `)。

**`INPUT ["プロンプト";] 変数[, 変数...]`** はキーボードから値を読みます。
- `"プロンプト";` のあとには `? ` が出ます。`;` の代わりに `,` を使うと `? ` は出ません。
- 複数の値はカンマで区切って入力します。
- 数が合わない、または数値として読めないときは `?Redo from start` と出て、入力をやり直します。

**`LINE INPUT ["プロンプト";] 文字列変数`** は 1 行をそのまま (カンマも含めて) 読みます。

### 代入と制御

| 文 | 説明 |
|---|---|
| `[LET] 変数 = 式` | 代入。`LET` は省略できる |
| `GOTO 行番号` | 指定の行へ飛ぶ |
| `GOSUB 行番号` / `RETURN` | サブルーチンの呼び出しと戻り |
| `IF 条件 THEN 文 [ELSE 文]` | 条件で分岐する。`THEN`・`ELSE` のあとに行番号を書くと、その行へ飛ぶ。`IF 条件 GOTO 行番号` も書ける |
| `FOR 変数 = 初期値 TO 終値 [STEP 増分]` / `NEXT [変数[, 変数...]]` | 繰り返し。初期値の時点で終値を越えていれば、1 回も実行しない |
| `END` | プログラムを終える |
| `STOP` | プログラムを止める (`Break in 行番号`)。`CONT` で続けられる |
| `REM 文字列` / `' 文字列` | コメント |

`IF` の `THEN` と `ELSE` には、`:` で区切った複数の文を書けます。条件が偽なら、その行の `ELSE` まで (なければ行末まで) を飛ばします。

### DATA と READ

| 文 | 説明 |
|---|---|
| `DATA 値, 値, ...` | データを並べる。文字列は引用符で囲んでも、囲まなくてもよい |
| `READ 変数[, 変数...]` | `DATA` の値を順に読む |
| `RESTORE [行番号]` | 次に読む `DATA` を先頭 (または指定の行) に戻す |

### 画面

| 文 | 説明 |
|---|---|
| `CLS [n]` | 画面を消す。1 (省略時) はテキスト、2 はグラフィック、3 は両方 |
| `LOCATE [x][, y]` | カーソルを x 桁 y 行目へ動かす (左上が 0,0) |
| `COLOR n` | 以後の文字の色をパレット番号 n (0〜15) にする |
| `WIDTH 80, 25` / `WIDTH 80, 20` | テキスト画面の行数を変える |

### グラフィック

座標は左上が (0,0)、右下が (639,399) です。画面の外にはみ出した部分は描かれません。
「色」を省略すると 7 (白) になります。

| 文 | 説明 |
|---|---|
| `PSET (x,y)[, 色]` | 点を打つ |
| `PRESET (x,y)[, 色]` | 点を打つ (色の省略時は 0 = 黒、つまり消す) |
| `LINE [(x1,y1)]-(x2,y2)[, [色][, B または BF]]` | 線を引く。`B` は四角、`BF` は塗りつぶした四角。始点を省くと直前に描いた位置から |
| `CIRCLE (x,y), 半径[, [色][, [開始角][, [終了角][, 比率]]]]` | 円を描く。開始角・終了角 (ラジアン、右が 0 で反時計回り) を指定すると円弧、負の角度ならその端から中心へ線を引く。比率は 縦÷横 で、0.5 なら横長の楕円 |
| `PAINT (x,y)[, 塗る色[, 境界の色]]` | 境界の色で囲まれた範囲を塗る。境界の色を省くと塗る色と同じ |
| `COLOR=(パレット番号, &HRGB)` | パレットの色を変える。描いたものの色もすぐに変わる |
| `COLOR=NEW` | パレットを初期値に戻す |

`&HRGB` は赤・緑・青を 0〜F で表します (例: `&HF80` はオレンジ)。

パレットの初期値:

| 番号 | 色 | 番号 | 色 |
|---|---|---|---|
| 0 | 黒 | 8 | 灰 |
| 1 | 青 | 9 | 暗い青 |
| 2 | 赤 | 10 | 暗い赤 |
| 3 | 紫 | 11 | 暗い紫 |
| 4 | 緑 | 12 | 暗い緑 |
| 5 | 水色 | 13 | 暗い水色 |
| 6 | 黄 | 14 | 暗い黄 |
| 7 | 白 | 15 | 暗い白 (灰) |

### 音

| 文 | 説明 |
|---|---|
| `BEEP` | 短いビープ音を鳴らす (Pi では HDMI の音声として鳴る) |

### ファイル

ファイルは Pi では SD カードの `P88/` フォルダに、PC 版では `./disk/` に、UTF-8 のテキストとして保存されます。
ファイル名は大文字になり、拡張子を省くと `.BAS` が付きます。

| 文 | 説明 |
|---|---|
| `SAVE "名前"` | プログラムを保存する |
| `LOAD "名前"[, R]` | プログラムを読み込む。`,R` を付けるとそのまま実行する |
| `FILES` | ファイルの一覧と大きさを表示する |
| `KILL "名前.拡張子"` | ファイルを消す (拡張子は省略できない) |

PC で書いたファイルも `LOAD` できます。BOM 付きや CRLF の改行でも構いません。行番号のない行があると `Direct statement in file` になります。

## 6. 関数

### 数値の関数

| 関数 | 値 |
|---|---|
| `ABS(x)` | 絶対値 |
| `INT(x)` | x を越えない最大の整数 (`INT(-2.5)` は -3) |
| `FIX(x)` | 小数部を切り捨てた値 (`FIX(-2.5)` は -2) |
| `SGN(x)` | 正なら 1、0 なら 0、負なら -1 |
| `SQR(x)` | 平方根 |
| `SIN(x)` `COS(x)` `TAN(x)` `ATN(x)` | 三角関数 (ラジアン) |
| `EXP(x)` `LOG(x)` | 指数関数、自然対数 |
| `RND` / `RND(x)` | 0 以上 1 未満の乱数。x が負なら乱数の種を x にし、0 なら直前の値を返す |

### 文字列の関数

文字の数え方は 1 文字単位です。全角文字も 1 文字と数えます (`LEN("あいう")` は 3)。

| 関数 | 値 |
|---|---|
| `LEN(s$)` | 文字数 |
| `LEFT$(s$, n)` `RIGHT$(s$, n)` | 左から・右から n 文字 |
| `MID$(s$, m[, n])` | m 文字目から n 文字 (省くと最後まで) |
| `INSTR([n,] s$, t$)` | s$ の n 文字目以降で t$ が最初に現れる位置。なければ 0 |
| `CHR$(n)` | 文字コード n (0〜65535) の文字 (`CHR$(&H6F22)` は「漢」) |
| `ASC(s$)` | 先頭の文字の文字コード |
| `STR$(x)` | 数値を `PRINT` と同じ書式の文字列にする (後ろの空白は付かない) |
| `VAL(s$)` | 文字列を数値にする。読めなければ 0 |
| `STRING$(n, c)` | 文字 c を n 個並べた文字列。c は文字コードか文字列 |
| `SPACE$(n)` | 空白 n 個 |
| `HEX$(x)` | 16 進の文字列 |

### 画面と入力の関数

| 関数 | 値 |
|---|---|
| `INKEY$` | 押されたキーを 1 文字返す。なければ空文字列。待たない |
| `POS(0)` | カーソルの桁 (0〜79) |
| `CSRLIN` | カーソルの行 (0〜24) |
| `POINT(x, y)` | その点の色番号。画面外なら -1 |

`INKEY$` が返す特殊キーの文字コード:

| キー | コード | キー | コード |
|---|---|---|---|
| → | &H1C | RET | &H0D |
| ← | &H1D | BS | &H08 |
| ↑ | &H1E | DEL | &H7F |
| ↓ | &H1F | HOME | &H0B |

## 7. エラー

エラーが起きるとプログラムは止まり、`Syntax error in 20` のように行番号付きで表示されます。

| メッセージ | 主な原因 |
|---|---|
| `Syntax error` | 文の書き方の誤り |
| `Undefined line number` | 存在しない行番号へ飛んだ |
| `Division by zero` | 0 で割った |
| `Type mismatch` | 数値と文字列の取り違え |
| `Overflow` | 値が大きすぎる |
| `Illegal function call` | 関数・文の引数が範囲外 |
| `Out of memory` | 配列が大きすぎる |
| `RETURN without GOSUB` | `GOSUB` なしで `RETURN` した |
| `NEXT without FOR` | 対応する `FOR` がない |
| `Out of DATA` | 読む `DATA` が残っていない |
| `Subscript out of range` | 配列の添字が範囲外 |
| `Duplicate Definition` | 同じ配列を 2 回 `DIM` した |
| `Can't continue` | `CONT` できない (プログラムを変更した後など) |
| `File not found` | ファイルがない |
| `Disk I/O error` | SD カードの読み書きに失敗した |
| `Bad file name` | ファイル名に使えない文字がある |
| `Direct statement in file` | `LOAD` したファイルに行番号のない行がある |

## 8. N88-BASIC との違い

- 画面は 640×400 ドット 16 色だけです。`SCREEN` はありません。
- 倍精度はありません (`#` は単精度として扱います)。
- 文字コードは Unicode です (Shift_JIS ではありません)。文字列は 1 文字単位で数えます。
- `COLOR=` の色は `&HRGB` で指定します。
- ファイルはテキスト形式だけで、中間コード形式のファイルは読めません。
- `ON GOTO`、`DEF FN`、`WHILE`、`PRINT USING`、`SOUND` など、まだない命令があります。
